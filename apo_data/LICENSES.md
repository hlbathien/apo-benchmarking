# Licenses and redistribution

Generated APO prompts, benchmark metadata, and the supplied annotations are
released for anonymous scientific review under the license in the companion
Software archive. Source code is released under the same review license.

Provider-generated response text is not redistributed in this archive. The
derived response records are limited to hashes and evaluation metadata. Model
names and provider identifiers are retained as scientific metadata; no blanket
license is asserted for provider-generated outputs.
