# Audit evidence status

The paper reports a 100-case, two-annotator blinded audit. The source workspace
contains neither completed individual labels nor consensus labels. This archive
therefore supplies the deterministic 100-case sample and a blank annotation
template, but it does not claim that the reported Cohen's kappa or 98/100
agreement can be reproduced from this review package. Add the completed,
de-identified label files before claiming the audit result is reproducible.
