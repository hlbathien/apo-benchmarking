# APO Data Artifact

This archive contains the anonymized data artifact for Adversarial Prior
Override (APO). Executable generation, scoring, validation, and table
reproduction code is provided in the OpenReview Software supplementary archive.

The paper corpus has 144 matched bundles and 576 prompts. It contains 9,216
derived response records from 16 reported model runs. Raw provider response
text is omitted from every record because this artifact has no written
redistribution permission for those outputs. The supplied response hashes,
parsed values, parse status, correctness, bait-hit indicators, token counts,
and proxy labels permit audit of the reported aggregates without redistributing
the raw text.
